- Guide: vault `Architecture/ALO_MODEL_IMPORT_GUIDE`; reference: `GameDesign/Corellian Battlecruiser Import`.
- Requested `Temp/ALO_MODEL_MAP.txt` is absent. Catalog `output/aotr-rebel-units/ship-catalog.csv` and installed AOTR XML resolve `R_Corellian_Battlecruiser` → `CV_Battlecruiser.ALO`, Workshop `1397421866`.
- `Prepare.py` resolves source inheritance and audits binary materials/bones, textures and unchanged input hashes. Four separate turret models are required for the art; their source weapons are excluded to preserve the requested 17-weapon loadout.
- Start portable Blender 3.6.23 with `Tools/Blender/Start-Blender.ps1`; verify MCP protocol 13 and the registered ALO operator. Create a fresh `CorellianBattlecruiser Source` scene and import the main ALO without animations.
- Run `uv run --with pillow python Tools/Blender/CorellianBattlecruiser/Prepare.py`, then `python Tools/Blender/CorellianBattlecruiser/GenerateConversionRequest.py`.
- Execute `uvx --from mcp-for-blender==2.1.3 python Tools/Blender/mcp_call.py Temp/CorellianBattlecruiserImport/ConvertRequest.json`. Save the printed `CONVERSION_JSON` object as `ConversionReport.json`; the request respects Blender safe mode.

ALAMO removes degenerate shadow-helper triangles; visible source material/triangle counts match exactly.
- ALAMO's global `hideLODs` scan requires objects to be in the current view layer. Borrowed objects are linked only during each turret import, then unlinked with their visibility restored.
- Run `Stage.py`, then Unity `BuildArt.cs` → `BuildGameplay.cs` → `Persist.cs` → `Render.cs` → `Register.cs` → `Inspect.cs`. Command: `unity command run_script --file Tools/Blender/CorellianBattlecruiser/<File>.cs --timeout_ms 60000 --json`; inspect nested `result.success`.
